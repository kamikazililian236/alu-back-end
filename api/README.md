# API - Back-end

Python scripts that use REST API to gather and export employee TODO data.

## Files

- 0-gather_data_from_an_API.py: Displays employee TODO list progress
- 1-export_to_CSV.py: Exports tasks to CSV
- 2-export_to_JSON.py: Exports tasks to JSON
- 3-dictionary_of_list_of_dictionaries.py: All employees to JSON
